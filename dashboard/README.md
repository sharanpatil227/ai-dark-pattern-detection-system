# AI-Powered Dark Pattern Detection System - Web Dashboard

Modern, responsive web dashboard built with React 18, Vite, Tailwind CSS, Lucide icons, and Recharts.

## Features
- **Real-Time Analytics**: View global statistics, risk distributions, and dark pattern frequency.
- **Interactive Scanning**: Test any URL or simulate DOM elements directly in the browser.
- **Detailed Audit Reports**: Comprehensive breakdown of detected patterns, evidence snippets, confidence metrics, and consumer recommendations.
- **Export & Print**: Clean, printable PDF format for research and compliance records.

## Setup & Running

```bash
cd dashboard
npm install
npm run dev
```

The application runs on `http://localhost:5173` with automated proxying to the FastAPI backend at `http://localhost:8000`.
